This is the editable visual companion to the first-launch decision workbook. It
maps the selected Build Season product wedge across:

- the canonical Event to Execution Moment object flow;
- the shared headless execution API used by GitHub, CLI, MCP, and web;
- Organizer, Project Lead, Builder, Reviewer, and Visitor action lanes;
- the identity, consent, private-evidence, and controlled-NIM boundaries;
- the normal builder route sequence;
- Project, reviewer, organizer, profile, Event, and public projections.

It is a product and wireframe argument, not an implementation plan. Candidate
decisions remain subject to the workbook approval and validation gates.

## Reading Order

1. Read the master execution graph from left to right.
2. Follow the relevant actor lane from left to right.
3. Inspect the concrete GitHub, CLI, MCP, and private-source examples.
4. Follow the top route row for the normal builder loop.
5. Read the bottom row as capability-scoped projections of the same frozen
   execution fact.

## Core Invariant

A person proves work once. Every authorized surface reuses the same frozen
fact, claim basis, attribution, and visibility ceiling.
